# Abhinay Kumar — portfolio

Source code for my [portfolio website](https://abhinay-portfolio-weld.vercel.app), built with React, TypeScript, Vite, and Three.js. It presents my projects, experience, writing, and contact links.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To check the production build:

```bash
npm run build
npm run preview
```

## Project structure

- `src/pages/` — site pages and project detail views
- `src/data/` — editable profile, project, experience, and skills content
- `src/three/` — interactive 3D scene
- `src/styles/` — global styles

Project descriptions on the website are portfolio content; the linked repositories provide the public implementation for projects that have one.
